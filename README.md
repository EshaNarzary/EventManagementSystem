## Project Description
The Event Management System is a web-based application that simplifies the planning,
organization, and management of events. It allows organizations to create events, manage
participant registrations, issue tickets, schedule event activities, and monitor attendance
through a centralized platform. It is suitable for seminars, workshops, conferences, cultural
programs, sports competitions, and corporate events.

## Technology Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git & GitHub
